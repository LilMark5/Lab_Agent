# 简历填写说明

这份简历是 Markdown 版，你可以直接用，也可以转成 Word/PDF 投递。

## 必须替换的占位符

- [你的手机号] / [你的邮箱] / [你的链接]
- [意向城市] / [到岗时间]
- [项目名称] / [技术栈] / [一句话说明]
- [CET-4/6 情况] / [证书竞赛]

## 填写原则

1. 手机、邮箱一定放真实的，GitHub 有就放，没有就先去创建一个放项目。
2. 项目经历只写“真做过、能讲清”的内容；面试官会顺着简历逐条问。
3. 每一条项目 bullet 尽量带动词和结果：实现 / 优化 / 降低 / 提升 / 验证。
4. 技能里不要写“精通”，实习生写“熟悉/了解”更可信。

## 导出建议

- 转 PDF：用 Typora 或 VS Code Markdown 预览打印成 PDF。
- 转 Word：需要的话我可以帮你生成 .docx 版本。
