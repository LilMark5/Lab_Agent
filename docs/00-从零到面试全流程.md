# 第 2 阶段：FastAPI 分层与数据库（第 2-3 天）

## 2.1 本节目标

理解“一次请求怎么从接口走到数据库”，并能自己加一个字段。

## 2.2 先看这些文件

```text
backend/app/main.py
backend/app/api/lab.py
backend/app/services/lab_service.py
backend/app/models/lab.py
backend/app/schemas/lab.py
backend/app/database.py
```

## 2.3 知识点：三层架构

```text
api/      接口层：接收参数、鉴权、调用 service，不写业务
services/ 业务层：事务、业务规则、异常
models/   ORM：数据库表对应的 Python 类
schemas/  契约：接口入参出参，和 models 分离
```

为什么要分 `models` 和 `schemas`？

- `models` 是数据库细节，比如 password 字段。
- `schemas` 是接口要暴露的东西，比如返回用户时不带 password。
- 分开后，数据库怎么改，前端接口契约不受影响。

## 2.4 代码逐行讲解：一个列表接口

打开 [backend/app/api/lab.py](../backend/app/api/lab.py)，看：

```python
@router.get("/list")
def get_lab_list(
    page: int = 1,
    page_size: int = 10,
    keywords: str | None = None,
    current_user: User = Depends(get_current_user),
    db: Session = Depends(get_db),
):
    res = lab_service.get_lab_page_list(db, page, page_size, keywords)
    return Response.success(data=res)
```

逐行：

- `@router.get("/list")`：声明一个 GET 接口，完整路径是 `/api/lab/list`。
- `page: int = 1`：查询参数，默认 1。
- `Depends(get_current_user)`：依赖注入，先解析 token 拿到当前用户。
- `Depends(get_db)`：依赖注入，给这个请求一个数据库 Session。
- 函数体只做两件事：调 service、返回统一响应。

打开 [backend/app/services/lab_service.py](../backend/app/services/lab_service.py)：

```python
query = db.query(Lab)
if keywords:
    query = query.filter(Lab.name.ilike(f"%{keywords}%"))
total = query.count()
items = query.order_by(Lab.id.desc()).offset((page-1)*page_size).limit(page_size).all()
```

逐行：

- `db.query(Lab)`：相当于 `SELECT * FROM labs`。
- `filter(...ilike(...))`：模糊查询，`ilike` 不区分大小写。
- `count()`：总数，用于分页组件。
- `order_by(id.desc())`：按 id 倒序。
- `offset/limit`：跳过前 N 条、取 M 条，就是分页。

## 2.5 知识点：数据库怎么建出来的

打开 [backend/app/database.py](../backend/app/database.py)：

```python
class Base(DeclarativeBase):
    id: Mapped[int] = mapped_column(primary_key=True, autoincrement=True)
    create_time: Mapped[datetime] = mapped_column(DateTime, default=datetime.now)
```

- `Base` 是所有模型的公共父类，定义公共字段 id/创建时间/更新时间。
- 模型继承 Base，声明字段和类型。
- `create_all` 把这些模型变成数据库表。

打开 [backend/app/models/lab.py](../backend/app/models/lab.py)：

```python
class Lab(Base):
    __tablename__ = "labs"
    name: Mapped[str] = mapped_column(String(50), nullable=False)
```

- `__tablename__` 是表名。
- `mapped_column(String(50))` 定义列类型和长度。
- `nullable=False` 表示不能为空。

# 第 3 阶段：JWT 鉴权（第 4 天）

## 3.1 本节目标

理解“登录一次，之后每个请求怎么被认出来”。

## 3.2 先看这些文件

```text
backend/app/utils/jwt.py
backend/app/utils/password.py
backend/app/dependencies/auth.py
backend/app/services/auth_service.py
```

## 3.3 知识点：登录和鉴权两件事

### 登录（auth_service.login）

```text
前端提交 username + password
  → 查数据库找用户
  → bcrypt 校验密码
  → 生成 token
  → 返回 {token, user}
```

### 鉴权（get_current_user）

```text
后续请求带 Authorization: Bearer <token>
  → 解析 token 拿 user_id
  → 查数据库确认用户存在且未被禁用
  → 返回 User 对象
```

## 3.4 代码逐行讲解：JWT

打开 [backend/app/utils/jwt.py](../backend/app/utils/jwt.py)：

```python
payload = {"user_id": user_id, "exp": expire}
return jwt.encode(payload, settings.JWT_SECRET_KEY, algorithm=settings.JWT_ALGORITHM)
```

- payload 放业务信息，`exp` 是过期时间。
- 用密钥签名，防止篡改。

解码：

```python
return jwt.decode(token, settings.JWT_SECRET_KEY, algorithms=[...])
```

验签失败、过期都会抛异常，调用方捕获后返回 401。

## 3.5 代码逐行讲解：密码

打开 [backend/app/utils/password.py](../backend/app/utils/password.py)：

```python
bcrypt.hashpw(password.encode(), bcrypt.gensalt())
bcrypt.checkpw(password.encode(), hashed.encode())
```

- bcrypt 带随机盐，同样密码每次哈希不同。
- 只能校验，不能还原，所以数据库泄露也不直接暴露明文。

## 4.3 知识点：响应式

Vue3 用 `ref` 和 `reactive` 让数据变成响应式：

```js
const count = ref(0)
// 模板里写 {{ count }}，count.value 变了，页面自动更新
```

区别：

- `ref`：基本类型，读写要 `.value`，模板里自动解包。
- `reactive`：对象，直接改属性。

最容易踩的坑：流式输出里必须用 reactive，否则“接口有数据、页面不刷新”。

## 4.4 代码逐行讲解：axios 封装

打开 [frontend/src/utils/request.js](../frontend/src/utils/request.js)：

```js
service.interceptors.request.use((config) => {
  const token = getToken()
  if (token) config.headers.Authorization = `Bearer ${token}`
  return config
})
```

请求拦截器：每次请求自动带 token，你就不用每个接口手写。

```js
service.interceptors.response.use(
  (response) => {
    const res = response.data
    if (res.code === 200) return res
    // 否则统一提示错误
  },
  (error) => { /* 处理 401 等 */ }
)
```

响应拦截器：统一判断 `code`，业务错误统一提示，401 清登录态跳登录页。

# 第 5 阶段：RAG 检索（第 7-9 天）

## 5.1 本节目标

理解“先查资料再回答”，并亲自动手加一篇知识文档验证。

## 5.2 先看这些文件

```text
backend/data/kb/*.md
backend/app/services/vector_store.py
backend/app/services/kb_service.py
backend/evaluate_rag.py
```

## 5.3 知识点：RAG 为什么存在

大模型有两个问题：知识截止、爱编造。RAG 的做法是：

```text
用户问题 → 检索相关知识 → 拼进 Prompt → 模型依据资料回答
```

所以模型不再“凭空猜”，而是“照着资料说”。

## 5.4 知识点：向量检索

把文本变成向量，语义相近的句子向量距离近。用户问“几点开门”，文档写
“开放时间”，关键词不同但语义近，所以能检索到。

## 5.5 知识点：混合检索

```text
向量召回（语义）   ┐
BM25 召回（关键词）├→ RRF 融合 → rerank 精排 → 给模型
```

为什么混合：向量管同义改写，BM25 管精确词，RRF 只按名次融合两路排序，
rerank 用交叉编码器再精排前几名。

## 5.6 代码逐行讲解：kb_service.search

打开 [backend/app/services/kb_service.py](../backend/app/services/kb_service.py)：

```python
vector_hits = _vector_search(query, top_k=5)
keyword_hits = _bm25_search(query, top_k=5)
merged = _rrf_fusion(vector_hits, keyword_hits)
merged = _rerank(query, merged)
```

# 第 7 阶段：LangGraph Agent（第 11-12 天）

## 7.1 本节目标

理解 Agent 是“一张图”，并完整走通一次智能预约。

## 7.2 先看文件

```text
backend/app/services/agent_service.py
```

## 7.3 知识点：State / Node / Edge

- State：图维护的共享状态，本项目是消息列表。
- Node：执行单元，如 agent（调模型）、tools（执行工具）。
- Edge：决定下一步去哪。

```text
START → agent → 有 tool_calls？ → tools → agent → …
                    ↓ 没有
                   END
```

`recursion_limit=10` 限制 agent 和 tools 来回次数，防死循环。

## 7.4 代码逐行讲解

打开 [backend/app/services/agent_service.py](../backend/app/services/agent_service.py)：

```python
graph = StateGraph(MessagesState)
graph.add_node("agent", agent_node)
graph.add_node("tools", ToolNode(tools))
graph.add_edge(START, "agent")
graph.add_conditional_edges("agent", tools_condition)
graph.add_edge("tools", "agent")
return graph.compile()
```

逐行：

- `StateGraph(MessagesState)`：以消息列表为状态建图。
- `add_node`：注册两个节点。
- `add_edge(START, "agent")`：从起点到 agent。
- `add_conditional_edges("agent", tools_condition)`：agent 结束后按条件分流。
- `add_edge("tools", "agent")`：工具执行完回到 agent 再看结果。

## 7.5 知识点：ReAct

ReAct = Reasoning + Acting：

```text
Thought 想 → Action 调工具 → Observation 看结果 → 再想 → 直到能回答
```

你上面的图就是 ReAct 的工程实现。面试能画出来就是加分。

## A.1 config.py：全局配置

文件：[backend/app/config.py](../backend/app/config.py)

```python
BASE_DIR = Path(__file__).resolve().parent.parent
```

`__file__` 是当前文件路径 `backend/app/config.py`；`parent` 是 `app`，
再 `parent` 是 `backend`。所以 `BASE_DIR` 就是后端根目录。

```python
class Settings(BaseSettings):

    JWT_SECRET_KEY: str = "dev-only-secret-key-change-me-in-production"
```

pydantic-settings 会按字段名去 `.env` 和环境变量里找值，找不到就用默认值。
这就是为什么配置能写在 `.env`，而不用改代码。

```python
model_config = SettingsConfigDict(
    env_file=BASE_DIR / ".env", env_file_encoding="utf-8", extra="ignore",
)
```

- `env_file`：指定读哪个 `.env`。
- `extra="ignore"`：`.env` 里多写的键不报错。

```python
settings = Settings()
if settings.HF_ENDPOINT:
    os.environ.setdefault("HF_ENDPOINT", settings.HF_ENDPOINT)
```

`setdefault` 只在不存在的才设置。sentence-transformers 下载模型时会读

## A.2 database.py：引擎与会话

文件：[backend/app/database.py](../backend/app/database.py)

```python
if settings.DATABASE_URL:
    engine = create_engine(settings.DATABASE_URL, pool_pre_ping=True, ...)
else:
    engine = create_engine("sqlite:///./lab_agent.db", connect_args={"check_same_thread": False})
```

- `engine` 是真正执行 SQL 的对象。
- 配了 `DATABASE_URL` 用 PostgreSQL/MySQL，没配用 SQLite。
- SQLite 是多线程问题，加 `check_same_thread=False`。

```python
SessionLocal = sessionmaker(bind=engine, autoflush=False, autocommit=False)
```

`SessionLocal` 是会话工厂，每次调用产出一个新的数据库会话。

```python
def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

这是 FastAPI 依赖。`yield` 之前是请求开始，`yield` 之后是请求结束；
无论中间成功还是报错，`finally` 都会关连接，防止泄漏。

```python
class Base(DeclarativeBase):
    id: Mapped[int] = mapped_column(primary_key=True, autoincrement=True)
    create_time: Mapped[datetime] = mapped_column(DateTime, default=datetime.now)
    update_time: Mapped[datetime] = mapped_column(DateTime, default=datetime.now, onupdate=datetime.now)
```

- `Base` 是所有模型的父类。
- `id` 主键自增。
- `create_time` 插入时自动填当前时间。
- `update_time` 更新时自动刷新（`onupdate`）。

## A.3 common/response.py：统一响应

文件：[backend/app/common/response.py](../backend/app/common/response.py)

```python
class Response(BaseModel):
    code: int
    message: str
    data: Any = None

    @classmethod
    def success(cls, message="请求成功", data=None):
        return cls(code=200, message=message, data=data)
```

所有接口都返回 `{code, message, data}`，前端只判断 `code`。

```python
class PageResponse(BaseModel):
```

分页统一返回 `{list, total}`。

## A.7 dependencies/auth.py：鉴权依赖

文件：[backend/app/dependencies/auth.py](../backend/app/dependencies/auth.py)

```python
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="/api/auth/login")
```

这个对象负责从请求头 `Authorization: Bearer xxx` 里取 token。

```python
def get_current_user(token: str = Depends(oauth2_scheme), db=Depends(get_db)) -> User:
    payload = decode_access_token(token)
    user_id = payload.get("user_id")
    user = db.query(User).filter(User.id == user_id).first()
    if user.status != 1:
        raise HTTPException(401, "用户被禁用")
    return user
```

- 解析 token 拿 user_id。
- 再从数据库查用户，确认存在且正常。

## B.3 kb_service.py：混合检索 + 重排 + 缓存

### 分词

```python

```

### BM25 关键词召回

```python

```

BM25 是经典的关键词检索打分算法，词频越高、越稀有，得分越高。

### RRF 融合

```python
item["rrf"] = item.get("rrf", 0) + 1 / (k + rank + 1)
```

RRF 只按名次打分：排名越靠前，贡献 `1/(k+rank+1)` 越大。
两路召回分数尺度不同，直接相加不公平，RRF 只排名次所以稳定。

### rerank

```python
model = CrossEncoder(settings.RERANK_MODEL)
scores = model.predict([(query, hit["doc"]) for hit in hits])
```

交叉编码器把“问题 + 文档”拼一起深度比较，比向量检索更准但更慢，
所以只精排前几名。

```python
cache_key = "rag:" + hashlib.md5(query.encode("utf-8")).hexdigest()
```

## D.3 SQLAlchemy ORM

### 它是什么

用 Python 类操作数据库表，不用手写 SQL。

### 最小骨架

```python
# minimal_orm.py
from sqlalchemy import create_engine, String, select
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column, Session

engine = create_engine("sqlite:///:memory:")   # 内存数据库

class Base(DeclarativeBase):
    pass

class User(Base):
    __tablename__ = "users"                    # 表名
    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(50))

Base.metadata.create_all(engine)              # 建表

with Session(engine) as db:                   # 会话
    db.add(User(name="马凯"))
    db.commit()
    user = db.scalar(select(User).where(User.name == "马凯"))
    print(user.id, user.name)
```

### 关键讲解

- `User` 类对应 `users` 表，字段对应列。
- `create_all` 建表，`Session` 管理事务。
- `db.add + commit` 插入，`select` 查询。这就是“对象关系映射”。

```python
           + datetime.timedelta(hours=1),
}
token = jwt.encode(payload, secret, algorithm="HS256")
print(token)
print(jwt.decode(token, secret, algorithms=["HS256"]))
```

### 关键讲解

- `exp` 是过期时间，PyJWT 会用它判断是否过期。
- 用密钥签名，别人改不了；但它是 Base64 编码，不是加密，别放密码。

## D.5 Redis

### 它是什么

### 最小骨架

```python
# minimal_redis.py（先 docker run -p 6379:6379 redis）
import redis

r = redis.Redis(host="127.0.0.1", port=6379, decode_responses=True)

```

### 关键讲解

- `incr` 原子自增，第一次设过期，形成固定窗口限流。

## D.6 PostgreSQL + pgvector

### 它是什么

PostgreSQL 是关系数据库，pgvector 扩展让它能存向量。

### 最小骨架

```sql
-- 先 docker run -p 5432:5432 -e POSTGRES_PASSWORD=123456 pgvector/pgvector:pg16

CREATE TABLE docs (
  id serial PRIMARY KEY,
  text text,
  embedding vector(3)      -- 3 维向量
);

INSERT INTO docs (text, embedding)
VALUES ('hello', '[1, 0, 0]');

-- 找与 [1,0,0] 最相似的

```

### 关键讲解

- `<=>` 是余弦距离算子，距离越小越相似。
- 这样业务数据和向量在同一套库，少一套存储。

## D.9 Embedding 与 RAG

### 它是什么

把文本变成向量，让“语义相近”变成“距离近”。

### 最小骨架

```python
# minimal_rag.py
from sentence_transformers import SentenceTransformer
import numpy as np

model = SentenceTransformer("BAAI/bge-small-zh-v1.5")

docs = [
    "实验室周一至周五 08:00-21:00 开放",
    "预约需要管理员审核",
]
query = "几点开门"

dv = model.encode(docs, normalize_embeddings=True)
qv = model.encode(query, normalize_embeddings=True)

sim = np.dot(qv, dv.T)          # 归一化后，点积就是余弦相似度
print(docs[int(np.argmax(sim))])
```

### 关键讲解

- embedding 模型把每个文本映射成固定长度向量。
- 向量归一化后，点积等于余弦相似度，越接近 1 越相关。
- RAG 就是：把问题向量化，找最相似的文档，拼进 Prompt。

## D.11 Tool Calling

### 它是什么

模型不直接执行函数，只输出“调哪个函数、传什么参数”，后端来执行。

### 最小骨架

```python
# minimal_tool.py
from langchain_core.tools import tool
from langchain_openai import ChatOpenAI

@tool
def add(a: int, b: int) -> int:
    """两个整数相加"""
    return a + b

llm = ChatOpenAI(model="gpt-4o-mini").bind_tools([add])
# 模型返回 tool_calls，真正执行 add 的是你的代码
```

### 关键讲解

- `@tool` 用函数签名 + docstring 生成 JSON Schema。
- `bind_tools` 把工具交给模型。
- 模型只“点单”，后端“做菜”，结果再塞回消息。

## D.12 ReAct

### 它是什么

推理 + 行动的循环：想一步、做一步、看结果、再想。

### 最小骨架（伪代码）

```python
for _ in range(3):                       # 限制轮数
    response = llm.invoke(messages)       # Thought -> Action
    if not response.tool_calls:
        return response.content           # 给出最终 Answer
    for call in response.tool_calls:
        result = execute(call)            # Observation
        messages.append(tool_message(result))
```

### 关键讲解

- Thought：模型决定下一步。
- Action：输出工具调用。
- Observation：后端把结果塞回。
- 循环直到没有工具调用，输出答案。

## D.13 LangGraph

### 它是什么

把 Agent 写成图：State 存状态，Node 干活，Edge 决定流转。

### 最小骨架

```python
# minimal_langgraph.py
from langgraph.graph import StateGraph, MessagesState, START, END

def echo_node(state: MessagesState):
    return {"messages": state["messages"]}

graph = StateGraph(MessagesState)
graph.add_node("echo", echo_node)
graph.add_edge(START, "echo")
graph.add_edge("echo", END)

compiled = graph.compile()

```

### 关键讲解

- `MessagesState` 是内置的消息列表状态。
- `add_node` 注册节点，`add_edge` 连线。
- 真实 Agent 再加一个 `tools` 节点和条件边，就是 ReAct。

## D.15 SSE 流式输出

### 它是什么

## D.1 FastAPI

### 是什么

FastAPI 是 Python 的 Web 框架，用来写后端接口。它自动生成 Swagger 文档，
用类型注解做参数校验，用依赖注入复用鉴权/数据库。

### 最小骨架

```python
from fastapi import FastAPI, Depends

app = FastAPI()


@app.get("/hello/{name}")
def hello(name: str, q: str = ""):
    # name 是路径参数，q 是查询参数
    return {"message": f"你好 {name}", "q": q}


def common_dep():
    return "这段被依赖注入"


@app.get("/dep")
def use_dep(value: str = Depends(common_dep)):
    return {"value": value}
```

运行：

```powershell
uvicorn main:app --reload
```

打开 `http://127.0.0.1:8000/docs` 就能在线调试。

### 核心概念

- 路由：`@app.get/post/put/delete` 定义接口。
- 路径参数：`{name}`；查询参数：函数参数默认值。
- `Depends`：依赖注入，先执行依赖函数，再把返回值传给接口。

## D.2 SQLAlchemy

### 是什么

SQLAlchemy 是 Python 的 ORM，把数据库表映射成类，用 Python 对象操作数据库。

### 最小骨架

```python
from sqlalchemy import create_engine, String, select
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column, Session


class Base(DeclarativeBase):
    pass


class User(Base):
    __tablename__ = "users"
    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(50))


engine = create_engine("sqlite:///:memory:")  # 内存数据库，重启即清空
Base.metadata.create_all(engine)               # 建表

with Session(engine) as session:
    session.add(User(name="马凯"))
    session.commit()                            # 提交事务
    users = session.execute(select(User)).scalars().all()
    print(users)  # [<User id=1 name='马凯'>]
```

### 核心概念

- `engine`：连接数据库。
- `Session`：一次事务，commit 才落库。
- `Mapped` + `mapped_column`：声明列。
- `select(User)`：查询。

## D.3 JWT

### 是什么

JWT 是一段签名过的字符串，服务端用密钥签发，客户端无法篡改。登录后发 token，
之后每个请求带 token，服务端验签识别身份。

### 最小骨架

```python
import datetime
import jwt

SECRET = "your-secret-key"


def create_token(user_id: int) -> str:
    payload = {
        "user_id": user_id,
        "exp": datetime.datetime.now(datetime.timezone.utc) + datetime.timedelta(hours=1),
    }
    return jwt.encode(payload, SECRET, algorithm="HS256")


def decode_token(token: str):
    return jwt.decode(token, SECRET, algorithms=["HS256"])


t = create_token(1)
print(decode_token(t))  # {'user_id': 1, 'exp': ...}
```

### 核心概念

- `payload`：业务信息 + `exp` 过期时间。
- 签名：防篡改，不是加密，别放密码。

## D.5 Redis

### 是什么

Redis 是内存数据库，常用来做缓存和限流。因为快、支持过期时间、命令原子。

### 最小骨架：限流

```python
import redis

r = redis.Redis.from_url("redis://127.0.0.1:6379/0", decode_responses=True)


def allow(user_id: int, limit: int = 20) -> bool:
    key = f"ratelimit:{user_id}"
    count = r.incr(key)          # 原子自增
    if count == 1:
        r.expire(key, 60)        # 第一次设置 60 秒过期
    return count <= limit
```

### 核心概念

- `INCR`：原子自增，并发安全。
- `EXPIRE`：设置过期时间。
- 二者组合实现“每分钟最多 N 次”。

## D.7 Embedding 与向量检索

### 是什么

Embedding 把文本映射成向量，语义相近的文本向量距离近。

### 最小骨架

## D.9 LangGraph

### 是什么

LangGraph 把 Agent 组织成图：Node 干活，Edge 决定流转，State 共享状态。

### 最小骨架：ReAct Agent

```python
from langchain_openai import ChatOpenAI
from langgraph.graph import START, MessagesState, StateGraph
from langgraph.prebuilt import ToolNode, tools_condition

llm = ChatOpenAI(model="gpt-4o-mini").bind_tools([add])


def agent(state: MessagesState):
    return {"messages": [llm.invoke(state["messages"])]}


graph = StateGraph(MessagesState)
graph.add_node("agent", agent)
graph.add_node("tools", ToolNode([add]))
graph.add_edge(START, "agent")
graph.add_conditional_edges("agent", tools_condition)
graph.add_edge("tools", "agent")
app = graph.compile()

result = app.invoke({"messages": [{"role": "user", "content": "1+2 等于多少"}]})
```

### 核心概念

- `MessagesState`：消息列表状态。
- `tools_condition`：有工具调用去 tools，否则结束。
- `recursion_limit`：限制来回次数。

## D.1 FastAPI 最小骨架

### 概念

FastAPI 用 Python 类型注解自动做参数校验、生成文档，并支持依赖注入和异步。

### 核心知识

- 路由装饰器：`@app.get`、`@app.post`。
- Pydantic 模型做请求体校验。
- `Depends` 依赖注入。

### 最小示例

```python
from fastapi import FastAPI, Depends
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str
    price: float

def get_db():
    # 模拟一个数据库会话
    return "db-session"

@app.get("/")
def root():
    return {"message": "hello fastapi"}

@app.post("/items")
def create_item(item: Item, db: str = Depends(get_db)):
    # item 已被 Pydantic 校验，db 由依赖注入提供
    return {"item": item, "db": db}
```

运行：

```powershell
uvicorn main:app --reload
```

打开 `/docs` 就能看到自动生成的文档。

## D.2 SQLAlchemy 最小骨架

### 概念

ORM 把数据库表映射成 Python 类，用对象操作代替手写 SQL。

### 核心知识

- `engine` 连数据库，`Session` 管事务。
- `Base` 是所有模型父类。
- `Mapped` + `mapped_column` 定义字段。

### 最小示例

```python
from sqlalchemy import create_engine, String, select
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column, Session

engine = create_engine("sqlite:///:memory:")

class Base(DeclarativeBase):
    pass

class User(Base):
    __tablename__ = "users"
    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(50))

Base.metadata.create_all(engine)

with Session(engine) as db:
    db.add(User(name="马凯"))
    db.commit()
    users = db.scalars(select(User)).all()
    print([u.name for u in users])  # ['马凯']
```

## D.3 JWT 最小骨架

### 概念

JWT 是签名字符串，服务端验签后信任里面的信息，无需每次查 Session。

### 核心知识

- `encode` 生成 token，`decode` 验证。
- `exp` 是标准过期字段。

### 最小示例

```python
from datetime import datetime, timedelta
import jwt

SECRET = "secret"

def make_token(user_id: int) -> str:
    payload = {"user_id": user_id, "exp": datetime.now() + timedelta(hours=24)}
    return jwt.encode(payload, SECRET, algorithm="HS256")

def read_token(token: str) -> dict:
    return jwt.decode(token, SECRET, algorithms=["HS256"])

t = make_token(1)
print(read_token(t)["user_id"])  # 1
```

## D.4 Vue3 最小骨架

### 概念

Vue3 用响应式数据驱动视图，数据变、页面自动变。

### 核心知识

- `ref` 基本类型，`reactive` 对象。
- `computed` 派生值，有缓存。
- 模板里 `{{ }}` 绑定，`@click` 绑定事件。

### 最小示例

```vue
<script setup>
import { ref, computed } from 'vue'

const count = ref(0)
const double = computed(() => count.value * 2)
</script>

<template>
  <button @click="count++">
    count: {{ count }}，double: {{ double }}
  </button>
</template>
```

## D.5 RAG / Embedding 最小骨架

### 概念

先把文档向量化存起来，查询时把问题也向量化，找最相似的文档，再交给 LLM。

### 核心知识

- embedding 把文本变向量。
- 归一化后点积就是余弦相似度。
- 检索后拼进 Prompt。

### 最小示例

```python
import numpy as np
from sentence_transformers import SentenceTransformer

model = SentenceTransformer("BAAI/bge-small-zh-v1.5")

docs = ["实验室开放时间是每天八点", "食堂供应午餐"]
doc_vecs = model.encode(docs, normalize_embeddings=True)

query_vec = model.encode("几点开门", normalize_embeddings=True)
scores = doc_vecs @ query_vec  # 归一化后点积 = 余弦相似度
best = int(np.argmax(scores))

print(docs[best])  # 实验室开放时间是每天八点
```

## D.6 Tool Calling 最小骨架

### 概念

模型不执行工具，只输出调用参数；后端执行后把结果塞回消息再问模型。

### 核心知识

- `tools` 参数给模型工具 Schema。
- 模型返回 `tool_calls`。
- 结果用 `role=tool` 塞回。

### 最小示例

```python
from openai import OpenAI

client = OpenAI(api_key="你的key", base_url="你的base_url")
tools = [{
    "type": "function",
    "function": {
        "name": "get_weather",
        "description": "查询城市天气",
        "parameters": {
            "type": "object",
            "properties": {"city": {"type": "string"}}
        }
    }
}]

res = client.chat.completions.create(
    model="你的模型",
    messages=[{"role": "user", "content": "北京天气怎么样"}],
    tools=tools,
)
print(res.choices[0].message.tool_calls)
```

## D.7 LangGraph 最小骨架

### 概念

LangGraph 把流程画成图：State 是状态，Node 干活，Edge 决定下一步。

### 核心知识

- `StateGraph` 建图。
- `add_node`、`add_edge`。
- `invoke` 跑一次。

### 最小示例

```python
from typing import TypedDict
from langgraph.graph import StateGraph, START, END

class State(TypedDict):
    value: int

def add_one(state: State):
    return {"value": state["value"] + 1}

g = StateGraph(State)
g.add_node("add", add_one)
g.add_edge(START, "add")
g.add_edge("add", END)

print(g.compile().invoke({"value": 1}))  # {'value': 2}
```

## D.8 MCP 最小骨架

### 概念

MCP 让模型用统一协议连接工具，像 USB 接口。

### 核心知识

- `FastMCP` 建服务。
- `@mcp.tool()` 把函数变成工具。

### 最小示例

```python
from mcp.server.fastmcp import FastMCP

mcp = FastMCP("demo")

@mcp.tool()
def add(a: int, b: int) -> int:
    """两个数相加。"""
    return a + b

if __name__ == "__main__":
    mcp.run(transport="stdio")
```

## D.9 Redis 最小骨架

### 概念

Redis 是内存键值库，常用作缓存和限流。

### 核心知识

- `set` 带过期时间。
- `incr` 原子自增。

### 最小示例

```python
import redis

r = redis.Redis.from_url("redis://localhost:6379/0")
r.set("name", "马凯", ex=60)
print(r.get("name"))  # b'\xe9\xa9\xac\xe5\x87\xaf'

count = r.incr("count")
if count == 1:
    r.expire("count", 60)
print(count)
```

## D.10 Docker 最小骨架

### 概念

容器把应用和依赖打包，任何机器都能一致运行；Compose 编排多个容器。

### 最小示例（docker-compose.yml）

```yaml
services:
  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"
```

运行：

```powershell
docker compose up
```

## D.11 Git 最小骨架

### 概念

Git 记录每次快照，支持回退、分支、多人协作。

### 最小操作

```powershell
git init
git add .
git commit -m "feat: init"
git checkout -b feature/demo
# 改完文件后
git add .
git commit -m "feat: demo"
git checkout main
git merge feature/demo
```

### 核心知识

- 工作区 → `add` → 暂存区 → `commit` → 本地仓库 → `push` → 远程。
- 已推送的提交不要 `reset --hard`，用 `revert`。
